# Farhad Sofizada Portfolio

This repository is the source for [farhadsofizada.github.io](https://farhadsofizada.github.io), a static GitHub Pages portfolio for Farhad Sofizada.

## Local Preview

Open `index.html` in a browser. No build step or package installation is required.

## Publish With GitHub Pages

The repository name already follows GitHub's user-site convention: `farhadsofizada.github.io`.

1. Push the `main` branch to GitHub.
2. In the repository's **Settings > Pages**, set the source to **Deploy from a branch**.
3. Select the `main` branch and the repository root (`/`).
4. GitHub publishes the site at `https://farhadsofizada.github.io`.

The `.nojekyll` file keeps GitHub Pages from processing the static files through Jekyll.
